Translate texts — HMI

Only rows whose Project texts Reference points to this HMI are changed. TIA source slot means the language column that currently contains the texts. The actual language is detected from the text content, even if the TIA column label is wrong.

If TIA uses a different ViewPath root than the HMI inventory, use Preview texts to discover it and select the correct device here. Only that root will be translated.

Local Ollama server — no OpenAI API key required.

Translation scope — shared by manual review and automatic import

Prepare translates at most this many texts. Automatic import uses the same batch size.

Limit for automatic import only. Leave empty to process all eligible texts.

Run Preview texts to count rows and unique source texts in this HMI.

Batch translate + import to TIA

Automated mode: Ollama translates one batch, then TIA imports and verifies it before the next batch begins. Unlike the manual review workflow above, individual translations are not approved before import. Use only after a successful pilot and project backup.

Example: batch size 5, total 50 = up to 10 verified TIA imports. This automatic mode imports after each batch without manual review; Prepare one batch (review) above never imports automatically.
