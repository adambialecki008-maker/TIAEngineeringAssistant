Function Blocks and Functions

Create new declaration-only FB/FC blocks or read existing blocks from TIA. Program logic remains in TIA Portal.

Function Blocks (FB)

Create a new FB interface with Input, Output, InOut, Static, Temp and Constant parameters. The new block is local until you implement it in TIA Portal.

Read Function Block from TIA

Read a consistent SCL, LAD or FBD FB. Declaration changes are local drafts only; nothing is written to TIA Portal.

Choose an Active PLC in Overview, then read available Function Blocks.

Functions (FC)

Create a new FC interface with Input, Output, InOut, Temp and Constant parameters. FC has no Static section or Instance DB.

Read Function from TIA

FC supports Input, Output, InOut, Temp and Constant declaration drafts. FCs cannot have Static data or Instance DBs.

Choose an Active PLC in Overview, then read available Functions.

Offline declaration dependencies

Read-only dependency report for local UDT, DB, FB/FC and Instance DB snapshots. Not a verified TIA compilation or import plan.

Instance DB inventory

Lists existing Instance DBs only. A direct owning-FB relation is shown only when Siemens Openness reports its name, type and number; otherwise it remains Unverified.

Choose an Active PLC in Overview, then read Instance DB inventory.

Translate texts — HMI

Choose Project texts (XLSX) or Text lists (XML) below. Scan Project texts, Text lists, or both independently. TIA source slot means the language column containing the original texts, even if its label differs from the language of the text.

If TIA uses a different ViewPath root than the HMI inventory, use Scan HMI / Count texts to discover it and select the correct device here. Only that root will be translated.

Local Ollama server — no OpenAI API key required.
